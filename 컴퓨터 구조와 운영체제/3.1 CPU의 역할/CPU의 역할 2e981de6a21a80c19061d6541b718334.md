# CPU의 역할

- **CPU**
    - 컴퓨터의 핵심 구성 요소
    - 모든 연산과 처리 담당
    - 컴퓨터의 두뇌 → 컴퓨터가 실행하는 모든 명령을 해석하고 처리하기 때문
    - 사용자 명령과 소프트웨어의 요청을 바탕으로 ㅅ데이터를 실시간으로 처리하고 결과 산출
    - CPU의 성능은 컴퓨터 시스템의 전반적인 속도와 효율성에 큰 영향
- **CPU 주요 역할**
    - **명령어 실행**
        - 컴퓨터에서 실행하는 모든 소프트웨어는 CPU가 처리해야 할 명령어로 이루어짐
        - 명령어들은 CPU 아키텍처에 맞춰 설계된 **명령어 집합**을 기반
        - CPU는 메모리에서 명령어를 가져와 해석하고 실행하는 과정 반복
        - CPU의 연산 속도가 높을 수록 이러한 명령어 처리 과정이 더 빠르게 이루어지므로 프로그램의 실행 속도도 빨라짐
    - **연산 처리**
        - CPU는 다양한 종류의 연산 수행 가능
        - 산술 연산뿐만 아니라 논리 연산과 비교 연산도 처리
        - 연산 기능은 단순한 계산뿐만 아니라 데이터 처리, 알고리즘 실행, 인공지능 모델 학습 등 다양한 분야에서 활용
        - 고성능 CPU는 복잡한 연산을 빠르게 처리할 수 있어, 과학 연구, 게임 그래픽, 빅데이터 분석 등에서도 중요한 역할
    - **제어 신호 처리**
        - CPU는 컴퓨터 내 여러 장치와 통신하며 시스템을 제어하는 역할 수행
        - CPU는 메모리, 입출력 장치, 저장 장치 등과 데이터를 주고 받기 위해 **제어 신호** 생성
        - 제어 기능이 없다면 컴퓨터 시스템의 여러 부품이 혼란을 일으키고 출동이 발생할 가능성 상승
    - **데이터 이동 및 저장**
        - CPU는 데이터를 가져오고 저장하는 역할도 수행
        - 프로그램을 실행하는 데 필요한 데이터를 메모리에서 가져오고 연산 결과를 메모리 또는 저장 장치에 기록
    - **프로세스 관리 및 멀티태스킹**
        - 컴퓨터는 동시에 여러 프로그램을 실행하는 **멀티태스킹** 기능 제공
        - CPU는 이러한 작업을 효율적으로 관리하는 역할
        - 운영체제는 실행해야 할 여러 프로세스를 CPU에 전달
        - CPU는 프로세스의 우선순위를 조정하고, 어떤 작업을 먼저 실행할지 결정
        - 스케줄링 기법을 활용해 CPU의 사용률을 최적화
        - 사용자는 여러 프로그램을 동시에 실행 가능, 백그라운드에서 다양한 작업이 원할하게 수행
