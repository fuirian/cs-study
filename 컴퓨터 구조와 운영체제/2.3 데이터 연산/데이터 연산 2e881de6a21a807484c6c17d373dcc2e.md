# 데이터 연산

- **데이터 연산**
    - 데이터를 처리하고 조작하는 모든 활동
    - 데이터를 입력받아 처리하고 결과를 출력하는 과정 포함
    - **입력**
        - 키보드, 마우스 등 입력 장치를 통해 입력 받음
        - 입력된 데이터는 컴퓨터의 메모리에 저장
    - **처리**
        - 입력된 데이터는 CPU의 ALU에서 처리
        - ALU는 다양한 연산을 수행해 데이터를 처리
    - **저장**
        - 처리한 데이터는 나중에 사용할 수 있도록 메모리나 보조 기억 장치에 저장
    - **출력**
        - 연산 결과는 모니터와 같은 출력 장치를 통해 사용자에게 표시

### 데이터 연산의 종류

- **산술 연산**
    - 숫자 데이터를 대상으로 수행하는 연산
    - 사칙연산과 나머지 연산 포함
    - 수학적 계산에 사용, 다양한 프로그래밍 언어에서 지원
    - 덧셈, 뺄셈, 곱셈, 나눗셈, 나머지
- **논리 연산**
    - 불 값을 대상으로 수행하는 연산
    - **불(boolean)**: 참과 거짓 두가지 값을 표현하는 데이터 타입
    - 주로 프로그래밍 언어의 조건문에서 사용
    - AND 연산, OR 연산, NOT 연산
- **비트 연산**
    - 데이터를 이진수로 변환해 각 비트 단위로 수행하는 연산
    - **비트 AND 연산**: 두 비트가 모든 1일 때만 1
    - **비트 OR 연산**: 두 비트 중 하나라도 1이면 1
    - **비트 XOR 연산**: 두 비트가 서로 다를 때만 1
    - **비트 NOT 연산**: 모든 비트를 반전
    - **비트 이동 연산(시프트 연산)**: 비트를 왼쪽 또는 오른쪽으로 이동. 이동 시 빈칸은 0

### 정수 연산 방법

- **덧셈**
    - 주 정수의 각 비트를 더함
    - 두 비트의 합이 2가 되면 해당 비트는 0으로 하고 다음 비트로 1을 자리 올림
- **뺄셈**
    - 수1의 2의 보수를 구한 후 수2와 더함
    - 결과로 나온 값의 보수를 구한 후 - 부호 추가
