# 메모리 유형

- 컴퓨터에서 메모리는 데이터 저장 방식과 사용 목적에 따라 다양한 유형으로 나뉨
- 데이터 저장 방식 ⇒ **휘발성 메모리, 비휘발성 메모리**
- 사용 목적 ⇒ **주 기억 장치, 보조 기억 장치**

### 저장 방식에 따른 분류

- **휘발성 메모리**
    - 전원이 공급되는 동안만 데이터를 유지하고 전원이 꺼지면 저장된 데이터가 사라짐
    - 데이터를 임시 저장하는 데 주로 사용
    - **RAM**: 데이터를 일시적으로 저장해 CPU가 데이터를 빠르게 처리할 수 있도록 지원 ****
        - **DRAM**
            - 컴퓨터 시스템에서 가장 널리 사용하는 메모리
            - 동적 메모리 방식으로 작동, 커패시터를 사용해 데이터 저장
            - 동적: 데이터를 유지하려면 지속적인 관리 필요
            - 주기적으로 데이터 리프레시
            - 대용량 데이터를 비교정 저렴한 비용에 저장 가능
            - 소비 전력이 적지만 SRAM에 비해 속도가 느림
            - 주 기억 장치에 사용
        - **SRAM**
            - 정적 메모리 방식으로 작동
            - 플립플롭을 사용해 데이터 저장
            - 정적 메모리 방식은 전원이 공급되는 동안에는 데이터를 유지할 수 있어 데이터를 리프레시 하지 않아도 됨
            - DRAM보다 빠르고 안정적이지만, 비싸고 용량이 제한적이며 소비전력이 큼
            - 캐시 메모리에 사용
- **비휘발성 메모리**
    - 전원이 꺼져도 데이터를 유지할 수 있는 메모리
    - **ROM**
        - 시스템 부팅에 필요한 프로그램이나 펌웨어를 저장하는 데 사용하는 읽기 전용 메모리
        - 저장된 데이터는 일반적으로 변경 불가, 특정 유형의 ROM은 제한된 방식으로 데이터 수정 가능
        - **PROM**
            - 사용자가 데이터를 한 번 기록할 수 있는 ROM
            - 데이터를 기록한 후에는 데이터를 수정하거나 삭제 불가, 영구 저장
            - 하드웨어 개발 단계에서 요구에 맞게 데이터를 영구적으로 저장해야 할 때 사용
        - **EPROM**
            - 자외선을 이용해 기록된 데이터를 지우고 재사용 가능
            - 데이터를 반복해서 쓰고 지울 수 있으나 특별 장비 필요
            - 개발 및 데스트 과정에서 하드웨어와 소프트웨어를 실험적으로 검증할 때 유용
        - **EEPROM**
            - 전기 신호를 사용해 데이터를 기록 수정 가능
            - EPROM보다 사용이 편리, 데이터 삭제와 쓰기를 개별 바이트 단위로 할 수 있어 더 정밀한 제어 가능
            - 소규모 데이터 저장에 적합, 하드웨어 설정 정보를 저장하는 용도
        - **플래시 메모리**
            - EEPROM의 한 종류
            - 블록 단위로 데이터를 삭제 기록 가능
                - **NAND 플래시 메모리**
                    - 여러 개의 메모리 셀이 직렬로 연결 → 데이터 저장 밀도가 높고 대량의 데이터를 효율적으로 저장 가능
                    - 제조 단가가 낮고, 빠른 데이터 처리 속도를 제공
                    - SSD, USB 플래시 드라이브, SD 카드
                - **NOR 플래시 메모리**
                    - 셀 병렬 연결 → 각 셀에 개별적으로 접근 가능
                    - 특정 데이터 주소에 직접 접근할 수 있으므로 읽기 속도가 NAND 플래시 메모리보다 빠름
                    - 용량이 작아서 펌웨어나 임베디드 시스템의 프로그램 코드를 저장하는 데 주로 사용

### 사용 목적에 따른 유형

- **시스템 메모리**
    - 운영체제와 프로그램을 실행하는 데 필요한 메모리 → 주로 RAM 사용
    - CPU가 실행 중인 프로그램의 데이터를 저장해 빠르게 접근 가능
    - 프로그램의 실행 속도와 성능에 큰 영향
- **캐시 메모리**
    - CPU에서 자주 사용하는 데이터를 임시로 저장하는 메모리
    - CPU와 RAM 사이에 위치
    - SRAM 사용, 속도가 매우 빠름
- **비디오 메모리**
    - 크래픽 카드에서 사용하는 메모리
    - 화면에 출력할 그래픽 데이터를 저장하고 처리
    - 고해상도 이미지, 게임, 영상 편집 등 그래픽 연산에 최적화
    - 최신 그래픽 카드에서 사용하는 GDDR 메모리 → GDDR6, GDDR6X
    - 그래픽 연산 성능을 높여 고품질 화면 제공
- **버퍼 메모리**
    - 장치 간 데이터 전송 속도 차이를 조정하는 임시 저장소 역할을 하는 메모리
    - 주로 CPU와 보조 기억 장치 사이에서 데이터를 효율적으로 전송하는 데 사용
- **가상 메모리**
    - 물리 메모리가 부족할 때 보조 기억 장치의 일부를 메모리처럼 사용하는 기술
    - 운영체제에서 관리
    - 실제 물리 메모리보다 더 큰 공간 제공
    - 멀티태스킹 환경에서 매우 중요
- **영구 저장소**
    - 전원이 꺼져도 데이터를 영구적으로 저장하는 장치
    - HDD, SSD, USB, CD/DVD
    - HDD → 대용량 데이터 저렴하게 저장
    - SSD → 빠른 데이터 접근 속도 제공
