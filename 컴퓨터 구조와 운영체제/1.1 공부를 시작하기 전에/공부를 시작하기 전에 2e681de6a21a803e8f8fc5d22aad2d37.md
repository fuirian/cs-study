# 공부를 시작하기 전에

### 컴퓨터 구조와 운영체제를 배우는 이유

- **컴퓨터 구조**
    - 컴퓨터가 어떤 방식으로 동작하는지, 어떻게 데이터를 처리하고 명령을 실행하는지 연구하는 학문
    - 컴퓨터가 어떻게 만들어지고 작동하는지를 배움
- **운영체제**
    - 컴퓨터가 원할하게 작동하게 도와주는 소프트웨어
    - 하드웨어 자원을 관리하고, 사용자가 프로그램을 실행할 수 있도록 돕는 역할
    - 컴퓨터를 원활하게 작동하는 데 필요한 이론과 기술을 연구하는 학문
- **장점**
    - 컴퓨터가 어떻게 작동하는지 이해 가능
    - 더빠르고 효율적인 프로그램을 만들 수 있음
    - 문제 해결 능력 향상
    - 하드웨어와 소프트웨어를 직접 설계 가능
    - 시스템 성능을 분석하고 개선

### 하드웨어와 소프트웨어

- 컴퓨터가 작동하려면 하드웨어와 소프트웨어가 필수
- 서로 밀접하게 연결되어 있으며, 함께 작동해야만 컴퓨터가 원하는 작업 수행 가능
- **하드웨어**
    - 컴퓨터를 구성하는 실제 부품
    - **중앙 처리 장치(CPU)**: 컴퓨터의 두뇌 역할. 모든 연산과 명령 처리
    - **메모리(RAM)**: 데이터를 일시적으로 저장하는 공간. 컴퓨터가 빠르게 작업할 수 있도록 도움
    - **보조 기억 장치(HDD, SSD)**: 데이터를 영구적으로 저장하는 장치
    - **입출력 장치(키보드, 마우스, 모니터 등)**: 사용자가 컴퓨터와 상호작용할 수 있도록 도움
- **소프트웨어**
    - 컴퓨터가 특정 작업을 수행하도록 지시하는 프로그램
    - **시스템 소프트웨어**
        - 하드웨어와 응용 소프트웨어 사이의 인터페이스를 제공
        - 컴퓨터 시스템의 기본 운영을 관리
        - 시스템의 유지, 관리, 성능 최적화 등을 목적
        - 대표적으로 운영체제와 유틸리티 프로그램이 포함
    - **응용 소프트웨어**
        - 사용자가 특정 작업이나 목적을 달성하기 위해 사용하는 소프트웨어
        - 사용자 인터페이스 제공
        - 응용 프로그램뿐만 아니라, 해당 프로그램을 보완하거나 확장하는 다양한 소프트웨어 모듈, 라이브러리, 플러그 인 등이 포함
- 하드웨어와 소프트웨어는 서로 의존하는 관계
- 하드웨어와 소프트웨어가 효과적으로 협력하면 더 좋은 성능과 사용자 경험을 제공
