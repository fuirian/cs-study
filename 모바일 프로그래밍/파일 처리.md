# 파일 처리

### 1. 내장 메모리 파일 처리

앱을 종료했다가 다음에 다시 실행할 때, 사용자가 이전에 작업하던 내용을 그대로 이어서 보여주고 싶을 때 사용하는 임시/영구 데이터 저장 방식

- **저장 위치**: **`/data/data/패키지명/files`** 폴더
    - 이 영역은 해당 앱의 **고유 전용 공간**이기 때문에 다른 외부 앱이 절대로 접근할 수 없으며 보안성이 높음
- **동작 원리 (Java I/O 스트림 활용)**
    - **파일 읽기**: Context 클래스가 제공하는 **`openFileInput()`** 메소드를 사용합니다. 이 메소드는 파일에서 데이터를 읽어올 수 있는 자바의 **`FileInputStream`** 객체를 반환
    - **파일 쓰기**: Context 클래스가 제공하는 **`openFileOutput()`** 메소드를 사용합니다. 이 메소드는 파일을 새로 쓰거나 기록할 수 있는 자바의 **`FileOutputStream`** 객체를 반환
    - 실제 데이터를 다룰 때는 자바 JDK 표준인 `read()`, `write()` 메소드를 함께 활용

### 2. 외장 메모리 (SD 카드) 파일 처리

대용량 미디어 파일(MP3, 사진, 동영상)이나 다른 앱과 공유해야 하는 공용 데이터를 다룰 때 스마트폰에 탑재된 가상/실제 SD 카드를 활용

- **경로 위치**: 주로 **`/sdcard`** 또는 **`/storage/emulated/0`** 폴더 하위를 사용
- **접근 권한 설정**
    - 외장 메모리는 내장 메모리와 달리 아무나 접근할 수 있는 공용 공간이기 때문에, 보안상 안드로이드 시스템에 "나 외장 메모리 건드릴 거야"라고 허락 필요
    - 반드시 **`AndroidManifest.xml`** 파일에 파일 읽기/쓰기 관련 퍼미션(Permission, 권한)을 등록해야만 코드가 정상 작동 (빠뜨리면 실행 시 에러 발생)
- Manifest 권한 등록 예시 코드

```
<uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE"/>
<uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE"/>
```

### 3. 외장 메모리 응용: 파일 목록 가져오기

- **`Environment.getExternalStorageDirectory()`**: 외장 메모리의 최상위 루트 경로를 안전하게 찾아주는 메소드
- **`File.listFiles()`**
    - 지정한 폴더 하위에 존재하는 모든 폴더 및 파일 목록을 **`File[]`** (파일 배열) 형태로 한꺼번에 반환
    - 이 배열을 반복문(`for`)으로 돌려서 파일 이름들을 추출해 활용
