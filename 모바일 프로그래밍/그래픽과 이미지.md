# 그래픽과 이미지

### 1. 그래픽의 핵심: 캔버스와 페인트

안드로이드 화면에 도형, 선, 점 등을 직접 그리기 위해서는 도화지 역할을 하는 클래스와 붓 역할을 하는 클래스 필요

- `Canvas`도화지
    - 화면에 무언가를 그릴 수 있는 영역을 제공하는 클래스
    - **좌표계 기준**: 화면의 왼쪽 상단이 (0, 0)이 되며, 오른쪽으로 갈수록 X축이 증가하고 아래로 갈수록 Y축 증가
    - 주요 메소드로 점을 찍는 `drawPoint()`
    - 선을 그리는 `drawLine()`
    - 원을 그리는 `drawCircle()`
- `Paint`붓
    - 그려지는 도형의 색상, 두께, 스타일, 그리기 모드 등 ‘어떻게 그릴 것인가’에 대한 속성을 지정하는 클래스
    - 동일한 원을 그리더라도 Paint 객체에 설정된 선의 두께(`strokeWidth`)나 색상(`color`)에 따라 화면에 완전히 다르게 표현됨

### 2. 이미지 처리의 기본: 비트맵(Bitmap)

안드로이드에서 이미지 파일(PNG, JPG등)을 가져와 캔버스에 표현할 때 `Bitmap` 클래스를 거치게 됨

- **비트맵의 활용**
    - 앱 내부에 포함된 리소스 파일뿐만 아니라 외장 SD 카드에 저장되어 있는 이미지 파일들을 가져와 화면에 출력할 때 사용
    - `res/drawable` 폴더에 이미지를 넣어두고 이를 커스텀 뷰의 `onDraw()`메소드 안에서 호출하여 화면에 그리기도 함
    - 캔버스에 비트맵을 출력할 때는 주로 `drawBitmap(picture, 시작x, 시작y, null)`형태의 메소드 사용

### 3. 이미지의 기하학적 변환

가져온 이미지를 단순히 그대로 보여주는 것뿐만 아니라, 캔버스 자체를 조작하여 이미지를 회전하거나 늘리는 등의 변환 작업 가능

이미지 파일 자체를 변환하는 것이 아니라, 캔버스에 기하학적 변화를 먼저 적용한 후 그 위에 이미지 파일을 출력하는 형태

- `rotate()`: 이미지를 지정한 각도만큼 회전
- `scale()`: 이미지를 가로/세로로 확대 또는 축소
- `translate()`: 이미지의 출력 위치를 이동
- `skew()`: 이미지를 평행사변형 형태로 기울이기 처리
