# 고급 위젯 다루기

### 1. 크로노미터 (Chronometer) - 시간 측정 위젯

단순히 현재 시간을 보여주는 `DigitalClock`, `AnalogClock`과 달리, 특정 시점부터 시간이 얼마나 흘렀는지 측정하는 타이머 위젯

- 멈춰 있는 타이머가 아니라 스톱워치처럼 초 단위로 올라가는 동적 위젯.
- **제어 메소드 3가지**
    - `start()` : 타이머 측정을 시작
    - `stop()` : 타이머 측정을 정지
    - `reset()` : 측정된 타이머 시간을 초기화

```kotlin
// 1. 전역 변수나 onCreate 내부에서 위젯 객체 가져오기
val chrono = findViewById<Chronometer>(R.id.chronometer1)
val btnStart = findViewById<Button>(R.id.btnStart)
val btnReset = findViewById<Button>(R.id.btnReset)

// 2. [시작 버튼] 클릭 이벤트 리스너 (람다식)
btnStart.setOnClickListener {
    // 🌟 핵심 : 현재 부팅 후 흐른 시간을 크로노미터의 '기준 시간'으로 세팅 (0초 효과)
    chrono.base = SystemClock.elapsedRealtime()
    
    // 타이머 가동 시작
    chrono.start()
}

// 3. [정지/초기화 버튼] 클릭 이벤트 리스너
btnReset.setOnClickListener {
    // 타이머 멈춤
    chrono.stop()
    
    // 화면에 표시된 숫자를 다시 0초 상태로 리셋
    chrono.base = SystemClock.elapsedRealtime()
}
```

### 2. 텍스트 자동 완성 (AutoCompleteTextView)

사용자가 글자를 입력할 때, 미리 등록해 둔 키워드 목록(배열)에서 일치하는 단어를 하단에 추천 리스트로 띄워주는 편리한 위젯

- **AutoCompleteTextView (단어 1개 완성)**
    - 오직 하나의 단어만 자동 완성을 지원
    - 구글 검색창이나 로그인 아이디 입력창처럼 한 줄에 하나의 완성된 단어만 들어갈 때 사용
- **MultiAutoCompleteTextView (여러 개 단어 완성)**
    - 쉼표(`,`)나 공백 같은 구분자를 기준으로, 한 입력창 안에서 여러 개의 단어를 연속해서 자동 완성
    - 이메일 수신인 지정(`hong@test.com, kim@test.com`)이나 인스타그램 태그 입력창을 만들 때 사용
    - 여러 단어를 분리해 인식할 수 있도록 코드 단에서 `setTokenizer()` 설정을 반드시 추가해야 정상 작동

### 3. 웹뷰 (WebView) - 앱 안의 웹브라우저

스마트폰 자체의 웹브라우저(크롬, 삼성인터넷 등)를 실행하지 않고, 내가 만든 앱의 한 영역에 웹 페이지(URL)를 직접 띄우는 뷰 컨테이너

- **WebViewClient 상속**
    - 웹뷰에 단순히 특정 주소를 로딩(`loadUrl`)하고 내부 링크를 클릭하면, 앱 안에서 페이지가 바뀌는 게 아니라 스마트폰의 기본 인터넷 브라우저가 새로 열려버리는 문제가 발생
    - 이를 막고 "무조건 내 앱 내부에서만 링크가 열리도록" 강제하기 위해 `WebViewClient` 클래스를 상속받는 커스텀 클래스를 정의
- **핵심 오버라이딩 메소드**
    - **`shouldOverrideUrlLoading()`**: 링크가 클릭되어 새로운 URL이 로딩되려고 할 때 시스템이 이를 가로채서 처리하는 메소드. 이 메소드를 오버라이딩하여 내부에서 웹뷰가 직접 주소를 받도록 가공해야 외부 브라우저 이탈방지
- **보너스 Manifest 권한**
    - 웹뷰를 통해 인터넷 페이지를 불러와야 하므로, 반드시 `AndroidManifest.xml` 파일에 인터넷 사용 권한(`<uses-permission android:name="android.permission.INTERNET"/>`)을 선언 (권한을 빠뜨리면 화면이 하얗게 나오고 접속되지 않습니다.)
