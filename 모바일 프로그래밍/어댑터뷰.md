# 어댑터뷰

### 1. 어댑터뷰(AdapterView)의 정의

- 여러 개의 항목(데이터)을 일정한 규칙에 따라 나열하여 화면에 보여주는 위젯들을 통칭하는 말
- **대표적인 종류**
    - **`ListView`**: 데이터를 위아래 세로 목록 형태로 보여주고 선택할 수 있게 하는 위젯
    - **`GridView`**: 바둑판(도표) 모양으로 데이터를 배치하는 위젯 (예: 사진 갤러리)
    - **`Spinner`**: 클릭하면 아래로 리스트가 팝업되어 하나를 고를 수 있는 드롭다운 위젯
    - **`Gallery`**: 사진이나 이미지를 가로 좌우 스크롤 형태로 보여주는 위젯

### 2. 어댑터(Adapter)의 핵심 역할

텍스트뷰(`TextView`)나 버튼(`Button`)은 XML에 글자만 적으면 화면에 바로 보임. 하지만 리스트뷰는 데이터가 10개일지, 100개일지 미리 알 수 없음.

이때 "데이터 원본"과 "보여줄 화면(어댑터뷰)" 사이에서 중간 다리 역할을 하며 데이터를 화면에 알맞게 채워주고 틀을 짜주는 객체가 바로 어댑터(Adapter). 안드로이드에서는 주로 **`ArrayAdapter`** 클래스를 기본으로 사용

- **동작 원리**
    1. 대량의 **데이터 원본**(예: 코틀린의 `String` 배열이나 리스트)을 준비
    2. 데이터 원본과 화면에 보여줄 한 칸의 모양(레이아웃)을 어댑터(`ArrayAdapter`)에 집어넣어 결합
    3. 완성된 어댑터를 **어댑터뷰(`ListView` 등)의 속성**에 연결해 주면 리스트 완성

### 3. 5단계 코딩 패턴

### 💻 XML 예시 (`activity_main.xml`)

```
<ListView
    android:id="@+id/listView1"
    android:layout_width="match_parent"
    android:layout_height="wrap_content" />
```

### 💻 Kotlin 코드 예시 (`MainActivity.kt`)

```
// 2단계: 리스트뷰에 나열할 원본 데이터(배열) 준비
val mid = arrayOf("히어로즈", "24시", "로스트", "빅뱅이론", "프렌즈")

// 3단계: findViewById로 XML의 리스트뷰 위젯을 코틀린 변수에 대응
val list = findViewById<ListView>(R.id.listView1)

// 4단계: 어댑터(ArrayAdapter) 생성 및 데이터 결합
// android.R.layout.simple_list_item_1은 안드로이드가 기본 제공하는 한 칸짜리 텍스트 틀입니다.
val adapter = ArrayAdapter(this, android.R.layout.simple_list_item_1, mid)

// 5단계: 생성된 어댑터를 리스트뷰 변수에 적용 (연결 완료!)
list.adapter = adapter

// ⭐ 보너스 단계: 리스트 항목을 클릭했을 때 이벤트 처리 (람다식)
list.setOnItemClickListener { parent, view, position, id ->
    // position은 사용자가 누른 항목의 인덱스 번호(0부터 시작)입니다.
    Toast.makeText(applicationContext, mid[position] + " 선택함", Toast.LENGTH_SHORT).show()
}
```
