# 안드로이드 4대 컴포넌트

안드로이드 애플리케이션을 구성하는 가장 기본적이고 핵심적인 빌딩 블록

각각 독립된 형태로 존재, 시스템이나 다른 앱과의 상호작용을 담당

새로운 컴포넌트를 만들면 반드시 `AndroidManifest.xml` 파일에 등록해야 시스템이 인식하고 실행 가능

### 액티비티(Activity)

- 사용자에게 보여지는 화면을 구성하는 가장 기본적인 컴포넌트
- 사용자와 직접 상호작용이 일어나는 공간
- 하나의 앱은 보통 여러 개의 액티비티로 구성
- **메인 액티비티**: 앱 실행 시 가장 먼저 뜨는 화면
- 눈에 보이는 화면이므로 자신만의 독자적인 생명주기를 가짐
- 로그인 화면, 상품 목록 화면, 상세 보기 화면 등 눈에 보이는 모든 페이지

### 서비스(Service)

- 사용자와 상호작용하는 눈에 보이는 화면없이, 백그라운드에서 장시간 실행되는 컴포넌트
- 앱이 종료되거나, 다른 화면으로 전환되어도 뒤에서 끊김없이 동작해야하는 작업을 처리
- 메인 스레드에서 실행되므로, 무거운 작업을 할 때는 별도의 스레드를 생성해 처리하는 것이 일반적
- 음악 플레이어 앱을 내리고 웹 서핑을 해도 음악이 계속 나오는 배경 재생 기능, 백신 프로그램의 실시간 바이러스 검사
- **서비스의 생명주기 메소드**
    - **`onCreate()`**: 서비스가 최초로 생성될 때 단 한 번 호출되는 메소드. 서비스가 실행되기 전 필요한 초기화 작업을 기입.
    - **`onStartCommand()`**: 이미 서비스가 생성된 상태에서 **`startService()`**가 호출될 때마다 실행되는 가장 핵심 메소드. 백그라운드에서 주기적으로 처리해야 할 실제 비즈니스 로직(예: 음악 재생 시작 등)을 여기에 코딩
    - **`onDestroy()`**: 서비스가 더 이상 사용되지 않아 완전히 소멸될 때 호출. 사용하던 메모리나 자원(예: 음악 재생 중지 및 릴리즈)을 깔끔하게 해제하는 코드 삽입
    - **`onBind()`**: 다른 컴포넌트와 서비스를 연결할 때 쓰이며, 만약 연결(바인딩)해서 쓸 서비스가 아니라면 단순하게 **`return null`** 처리

### 브로드캐스트 리시버(Broadcast Receiver)

- 안드로이드 OS 시스템이나 다른 앱으로부터 전달되는 장기적, 비정기적인 방송 메시지를 감지하고 대응하는 컴포넌트
- 대개 화면이 없는 상태로 대기하다가, 특정 시스템 이벤트가 발생하면 이를 가로채서 앱에 알려줌
- 메시지가 수신되면 `onReceive()` 메소드가 자동으로 호출되어 지정된 작업을 수행
- 배터리가 5% 남았을 때 “배터리가 부족합니다”라는 경고창을 띄우거나, 문자가 왔을 때 상단 알림 방에 메시지를 표시하는 기능
- **브로드캐스트 리시버(BR)의 등록과 해제**
    
    배터리 방전이나 문자 수신 같은 시스템 방송 신호를 가로채는 `브로드캐스트 리시버`는, 무작정 켜두면 스마트폰 배터리를 엄청나게 많이 사용
    
    그래서 안드로이드 앱 화면(액티비티)이 켜질 때(눈에 보일 때) 등록하고, 꺼질 때(화면이 가려질 때) 반드시 해제하는 안전장치를 코딩
    
    - **`onResume()` 메소드 (등록)**: 액티비티가 사용자와 상호작용하기 직전에 활성화되는 시점. 이때 인텐트 필터(IntentFilter)를 생성하여 감지하고 싶은 액션(예: `ACTION_BATTERY_CHANGED`)을 추가한 후, 리시버를 시스템에 등록
    - **`onPause()` 메소드 (해제)**: 액티비티가 화면에서 사라지거나 정지되기 직전 시점. 이때 등록해 둔 리시버를 반드시 시스템에서 해제(`unregisterReceiver`)해 주어야 배터리 낭비와 메모리 누수를 막을 수 있음.

### 콘텐트 프로바이더(Content Provider)

- 앱 간에 안전하게 데이터를 공유할 수 있도록 데이터 접근 통로를 제공하는 컴포넌트
- 안드로이드는 보안상 자기 앱의 데이터에 외부 앱이 접근하는 것을 기본적으로 차단
- 다른 앱이 내 데이터를 조회하거나 수정할 수 있도록 허용하고 싶을 때, 이 콘텐트 프로바이더를 통해 안전한 인터페이스를 외부에 노출
- 카카오톡이나 토스 같은 앱이 사용자의 스마트폰에 저장된 ‘연락처’ 데이터나 ‘갤러리’ 데이터에 접근하여 목록을 가져올 때 사용
