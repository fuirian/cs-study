# 메뉴와 대화상자

### 1. 옵션 메뉴(Option Menu) vs 컨텍스트 메뉴(Context Menu)

두 메뉴는 화면에 나타나는 원인(트리거)과 출력되는 형태가 완전히 다름

1. **옵션 메뉴 (Option Menu)**
    1. 화면 전체에 영향을 주거나 앱의 전반적인 설정을 다루는 메뉴
    2. 스마트폰의 메뉴 버튼을 누르거나, 화면 오른쪽 위의 점 3개 아이콘(액션바/툴바의 더보기 버튼)을 눌렀을 때 나타남
    3. 목록이 많으면 위쪽으로 쌓여 출력되거나 스크롤이 가능. 보통 XML 파일을 만들어 생성
2. 컨텍스트 메뉴 (Context Menu)
    1. 특정 위젯(버튼, 텍스트 등)에 종속되어, 그 위젯만을 위한 추가 기능을 제공하는 메뉴 (PC에서 마우스 우클릭했을 때 뜨는 메뉴와 같은 개념)
    2. 메뉴와 연결된 특정 위젯을 '롱클릭(길게 누름)' 했을 때 보임
    3. 일반적으로 상단에 제목(Title)과 함께 화면 중앙에 팝업창 형태로 출력
    4. 어떤 위젯에 이 메뉴를 붙일 것인지 Kotlin 코드에서 `registerForContextMenu(위젯변수)` 함수를 통해 반드시 등록

### 2. 대화상자 (AlertDialog) 구조 분석

사용자에게 긴급한 메시지를 전달하거나 확인/취소 등의 선택권을 요구할 때 사용하는 팝업창

안드로이드에서는 **`AlertDialog.Builder`** 객체를 이용해 단계별로 빌드

1. **`setTitle()`**: 대화상자의 맨 위에 들어갈 제목 설정
2. **`setMessage()`**: 대화상자 본문에 들어갈 실제 내용(메시지 문자열) 설정
3. **`setPositiveButton()`**: 사용자가 동의나 확인을 누를 때 사용하는 긍정적 버튼을 생성. 클릭 시 작동할 람다식 이벤트 리스너를 내부에 구현

> **추가로 알아둘 버튼 메소드**
> 
> - `setNegativeButton()`: 취소나 거절을 뜻하는 부정적 버튼
> - `setNeutralButton()`: 무시나 보류를 뜻하는 중립 버튼
- 실제 구현 코드 틀 흐름

```
// 1. 빌더 객체 생성
val builder = AlertDialog.Builder(this)

// 2. 제목, 메시지, 버튼 순차적으로 설정 (체이닝 기법 가능)
builder.setTitle("알림 창 제목")
builder.setMessage("이곳에 내용을 입력합니다.")
builder.setPositiveButton("확인") { dialog, which ->
    // '확인' 버튼을 눌렀을 때 실행할 코드 처리 (토스트 팝업 등)
}

// 3. 마지막에 생성하고 화면에 출력하는 메소드 세트 (중요!)
builder.show()
```

### 3. 토스트 (Toast)

사용자에게 가벼운 피드백 메시지를 잠깐 보여주었다가 별도의 조작 없이 자동으로 사라지는 간편한 알림 형태

- **핵심 메소드**: `Toast.makeText(컨텍스트, "출력할 내용", 노출시간).show()`
