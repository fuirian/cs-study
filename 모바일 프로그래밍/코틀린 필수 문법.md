# 코틀린 필수 문법

### 1. 변수 선언 방식 및 데이터 형식

- 코틀린은 변수를 선언할 때 데이터 형식을 명시하지 않아도 대입되는 값에 따라 형식이 자동으로 지정되는 **암시적 선언** 지원
- 초기화를 하지 않고 변수를 선언할 때는 데이터 형식을 반드시 명시해야 함
- **`var`(variable)**
    - 일반 변수를 선언 할 때 사용
    - 필요할 때마다 값을 계속 변경 가능
    
    ```kotlin
    var myVar : Int = 100
    myVar = 200 //정상 작동
    ```
    
- **`val`(value)**
    - 읽기 전용 변수를 선언할 때 사용
    - 한 번 값을 대입하고 나면 값 변경 불가능
    
    ```kotlin
    val myVal : Int = 100
    myVal = 200 //오류 발생!
    ```
    
- **주요 데이터 형식**
    - **문자형**: `Char`, `String`
    - **정수형**: `Byte`, `Short`, `Int`, `Long`
    - **실수형**: `Float`, `Double`
    - **불리언형**: `Boolean`

### 2. Null 안전성(`?`와 `!!`)

- 프로그램의 안정성을 높이기 위해 기본적으로 변수에 null값을 넣지 못하도록 설계됨
- **`?`연산자**
    - 데이터 형식 뒤에 `?` 를 붙여주어야 `null`값 대입 가능
    
    ```kotlin
    var notNull : Int = null //오류 발생
    var okNull : Int? = null //정상 작동
    ```
    
- **`!!` 연산자**
    - 변수가 절대로 `null`값이 아니라고 프로그래머가 강제로 표시할 때 사용
    - `null`값이 들어가면 실행 시 오류 발생

### 3. 조건문(`if`, `when`)

- **`if`문(이중 분류)**
    - 조건식의 결과가 true인지 false인지에 따라 실행할 블록 결정
    
    ```kotlin
    if(count >= 90){
    	println("합격 (장학생)")
    } else if (count >= 60) {
    	println("합격")
    } else {
    	println("불합격")
    }
    ```
    
- **`when`문(다중 분류)**
    - java의 `switch`문을 대체하는 문법
    - 여러 가지 경우에 따라 선택하여 작업 실행
    
    ```kotlin
    when(score) {
    	100, 90 -> println("합격(장학생)")
    	80,70,60 -> println("합격")
    	else -> print("불합격")
    }
    ```
    

### 4. 반복문(`for`, `while`)

- **`for`문**
    - 주로 배열이나 컬렉션의 요소를 하나씩 순회할 때 사용
    - 인덱스 없이 요소의 내용이 변수에 대입되면서 배열의 개수만큼 반복 실행
- **`whlie`문**
    - 조건식이 `true`인 동안 블록 내부를 계속 반복
- **흐름제어**
    - 반복문을 즉시 빠져나갈 때는 `break`문
    - 반복문의 조건식으로 바로 건너뛸 때는 `continue`문

### 5. 메소드 및 변수의 범위

- **메소드 정의**
    - 기본 `main()` 함수 외에 개발자가 별도로 생성 가능
    - 호출 시 파라미터를 넘기거나 결과값을 `return` 문으로 반환
- **전역변수(Global Variable)**
    - 모든 메소드에서 공통으로 자유롭게 접근하고 사용할 수 있는 변수
- **지역변수(Local Variable)**
    - 특정 메소드 내부에서만 선언되어 해당 메소드 안에서만 사용되고 소멸하는 변수

### 6. 예외 처리(`try~catch`)

- 프로그램 실행 중에 뜻하지 않게 발생하는 오류(Exception)를 처리하여 앱이 강제 종료되는 것을 막아줌
- `try`블록 내부의 코드를 실행하다가 오류가 발생하면 가차없이 `catch`블록으로 이동하여 예외 처리 코드 수행

### 7. 람다식(`Lambda Expression`)

- 함수를 익명 함수 형태로 간단하게 표현한 기법
- 코드가 매우 간결해져 가독성이 높아짐
- 안드로이드에서 버튼 클릭 이벤트 리스너를 구현할 때 필수적으로 사용
- **특징**
    1. 함수를 `{ }`로 감싸며, `fun` 예약어 미사용
    2. `{ }`내부에서 `→`의 왼쪽은 파라미터 오른쪽은 함수의 본문 내용 작성
    3. `→` 오른쪽 문장이 여러 개일 경우 세미콜론으로 구분
    4. 내용 중 맨 마지막 문장의 실행결과가 자동으로 반환값이 됨
