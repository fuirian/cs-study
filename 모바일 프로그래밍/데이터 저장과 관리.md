# 데이터 저장과 관리

### 1. 데이터베이스(DB)의 기본 개념

- **데이터베이스(Database, DB)**
    - 대용량의 데이터 집합을 체계적으로 구성하여 컴퓨터 시스템에 저장해 놓은 것
- **DBMS (데이터베이스 관리 시스템)**
    - 데이터베이스를 체계적으로 생성, 관리하고 여러 사용자나 시스템이 데이터를 안전하게 공유할 수 있도록 지원하는 소프트웨어
    - 유형으로는 계층형, 망형, 관계형, 객체지향형, 객체관계형 등이 존재
- **관계형 데이터베이스(RDBMS)**
    - 현재 실실적으로 가장 많이 사용되는 유형
    - 업무 변화에 유연하게 대처할 수 있고, 대용량 데이터 관리와 데이터 무결성(Integrity)을 잘 보장한다는 장점

### 2. 안드로이드의 내장 DBMS: SQLite

안드로이드 시스템에는 별도의 서버 가동 없이 앱 내부에서 독립적으로 사용할 수 있는 가볍고 컴팩트한 RDBMS인 **SQLite**가 기본 내장

관계형 데이터베이스는 데이터를 표(Table) 형태로 관리

- **열 (Column / 필드)**
    - 테이블의 세로축을 의미하며, 데이터의 종류(속성)
    - 예: 이름, 전화번호, 아이디
- **행 (Row / 레코드 / 튜플)**
    - 테이블의 가로축을 의미하며, 데이터 종류들에 맞춰 실제로 입력된 하나의 데이터 세트(실제 데이터 값)

### 3. 핵심 SQL 명령어

SQLite를 제어하고 소통하기 위해 사용하는 표준 구조화 질의 언어(SQL) 문법

- **테이블 생성**: `CREATE TABLE 테이블명 (폴더명 데이터타입, ...);`
- **데이터 삽입**: `INSERT INTO 테이블명 VALUES (값1, 값2, ...);`
- **데이터 조회**: `SELECT 열이름 FROM 테이블명 WHERE 조건;`
    - 테이블의 모든 내용을 조회할 때는 열이름 대신 별표()를 사용하여 `SELECT * FROM 테이블명;` 과 같이 작성

### 4. 안드로이드 SQLite 프로그래밍 필수 클래스

안드로이드 스튜디오에서 코틀린 코드로 SQLite를 다룰 때 반드시 상속받거나 활용해야 하는 핵심 컴포넌트 3가지

1. `SQLiteOpenHelper` 클래스
    1. 데이터베이스를 최초로 생성하거나, 앱 업데이트로 인해 테이블의 구조(버전)를 변경해야 할 때 관리를 도와주는 도우미 클래스
    2. **필수 오버라이딩 메소드**
        1. **`onCreate()`**: 데이터베이스 파일이 최초로 생성될 때 단 한 번 호출. 보통 이곳에 `CREATE TABLE` 명령어를 넣어 테이블을 처음 생성
        2. **`onUpgrade()`**: 데이터베이스의 버전이 올라갔을 때 호출. 기존 테이블을 삭제(`DROP TABLE`)하고 새 스키마로 다시 생성하는 등의 처리
2. `SQLiteDatabase` 클래스
- 실제 데이터베이스 파일에 연결하여 SQL 문을 실행하는 제어권을 가진 클래스
- **주요 메소드**
    - `writableDatabase`: 데이터의 삽입, 수정, 삭제(Insert, Update, Delete)를 수행할 수 있도록 읽고 쓰기 가능한 DB 객체를 반환
    - `readableDatabase`: 데이터 조회(Select)를 할 수 있도록 읽기 전용 DB 객체를 반환
    - `execSQL()`: 결과값이 없는 SQL 문(Create, Insert 등)을 실행할 때 사용
    - `rawQuery()`: 결과값(행 집합)을 반환하는 Select 문을 실행할 때 사용
1. `Cursor` 인터페이스
    1.  `rawQuery()`를 통해 조회된 Select 문의 결과(행 집합)를 참조하고 순회할 수 있게 해주는 데이터 인터페이스
    2. 커서가 가리키는 위치를 한 행씩 밑으로 내리며(`moveToNext()`) 데이터를 차례대로 꺼내어 에디트텍스트나 리스트뷰 같은 화면 위젯에 출력할 때 사용
